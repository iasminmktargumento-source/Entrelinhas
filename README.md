# Entrelinhas

Site pessoal de escrita e worldbuilding (manuscrito, wiki, mapas, timeline, metas e mais).

- Versão no Claude: aberta pelo claude.ai (usa as funções do Claude: sinônimos, nomes, narração, backup no Google Docs).
- Versão independente: este repositório, publicado pelo GitHub Pages. Funciona sem internet e pode ser instalada como app (no Chrome/Edge: ícone de instalar na barra de endereço; no celular: "Adicionar à tela inicial").

Os livros da versão independente ficam guardados no navegador de cada aparelho. Faça backups (rodapé da barra lateral) e, para levar livros de uma versão para a outra, use Ajustes › Backup › "Backup de todos os livros" e depois "Importar".
